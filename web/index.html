1. 点击上方按钮, 在学校官方页面完成登录(与直接访问教务系统完全一致);
2. 登录成功后浏览器跳到 jw.xmu.edu.cn/new/index.html, 地址栏会带有 ?ticket=ST-...;
3. 点击下方书签工具一键返回本应用(先拖到书签栏, Chrome 可按 Cmd+Shift+B 显示); 或复制地址栏网址, 回到本页粘贴同步。
⭐ 拖我到书签栏 · 一键返回
⚠️ 通过复制 Chrome 配置档案提取登录态(不解密真实文件, 不影响 Chrome 运行)。需先在 Chrome 里登录过教务系统; 若提示未找到登录态, 请关闭 Chrome 后重试。
最省事的复制法: 在浏览器登录教务系统后, F12 → 应用/Application → Cookies → jw.xmu.edu.cn, 列表里点第一行, 按住 Shift 点最后一行全选, Cmd/Ctrl+C, 直接粘贴到上面(表格格式会自动识别, 无需手动整理)。
